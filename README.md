# JARVIS 私人语音助理

一个原创的科幻风私人 AI 助理原型，支持实时语音对话、文字指令和受控任务工具。

## 启动

1. 安装 Node.js 20 或更新版本。
2. 运行 `npm install`。
3. 复制 `.env.example` 为 `.env`，填入 DeepSeek API Key。
4. 运行 `npm run dev`，打开终端显示的网址。

没有 API Key 时，界面和文字任务会自动进入演示模式。

## 已有能力

- 浏览器语音识别、DeepSeek 推理与系统语音播报。
- 免费 Edge TTS 服务端中文神经网络语音，不依赖浏览器内置朗读功能。
- 最多保存 200 条本地长期记忆，支持相关记忆检索、安全过滤和确认删除。
- CORE 设置中心：切换 DeepSeek 模型、管理记忆容量与内容、调整 TTS 音色和机器人效果。
- 本地备忘、专注计时、读取时间、经确认后打开网站。
- 高影响操作必须先确认，API Key 仅保留在服务器端。
- 自适应科幻 HUD、对话记录与任务队列。

## 后续扩展

可继续接入日历、邮件、智能家居和桌面控制。每个外部能力应作为独立工具，并设置权限范围、操作日志和确认步骤。
